AUDIT SCOPE

1. SITEMAP CRAWL

- Confirm whether all sitemap URLs exist in the new build.

2. URL PARITY CHECK
For every URL in the sitemap, compare current live site vs new build and check:
- HTTP status code
- Final resolved URL
- Whether slug/path is unchanged
- Whether trailing slash behaviour is consistent
- Whether there are uppercase/lowercase duplicates
- Whether any URL is missing or moved

If a page is missing in the new build:
- flag it clearly
- suggest the most relevant 301 redirect target if appropriate

3. INDEXABILITY + ROBOTS
Check every tested page for:

- robots.txt blocking issues

- accidental noindex or disallow rules

Flag any page that should be indexable but is not.

4. CANONICAL AUDIT
Check canonicals on all tested pages and flag:
- canonicals pointing to preview, staging, Replit, or Vercel URLs
- canonicals pointing to the wrong live URL
- missing self-referencing canonicals
- canonical chains
- canonical mismatches with sitemap URLs
- canonicals on pages that resolve elsewhere

All production canonicals should point to:
https://www.voiceoverguy.co.uk/...

5. META + HEADING PARITY
For each page compare:
- page title
- meta description
- H1
- main page intent

Flag:
- missing titles
- missing meta descriptions
- titles that changed substantially without clear reason
- H1 missing or changed in a way that may alter search intent
- pages where the new version appears weaker, thinner, or less commercially focused than the current live page

Do not obsess over tiny wording differences. Focus on SEO-significant differences.

6. INTERNAL LINKING AUDIT
Check and compare internal links across the site and flag:
- broken internal links
- orphan pages
- pages in sitemap with weak or no internal links
- important old internal links missing from the new build
- nav/footer/body links that now point incorrectly
- dead links that still exist
- opportunity to preserve or improve internal linking without changing the core site structure

Pay special attention to key commercial and reputation pages such as:
- homepage
- male voiceover related pages
- British voiceover related pages
- English voiceover related pages
- Santa / Christmas voiceover pages
- David Attenborough pages
- important ranking blog posts

7. STRUCTURED DATA AUDIT
Check whether structured data exists and whether it has been preserved or improved appropriately.

- Person / Profile signals
- LocalBusiness where relevant
- BreadcrumbList
- BlogPosting on blog posts
- VideoObject where videos exist
- AudioObject where audio exists
- FAQPage only where genuinely appropriate

Flag:
- missing schema that exists on the current site
- broken JSON-LD
- invalid fields
- schema pointing to wrong URLs
- missing absolute URLs
- missing ISO dates where needed
- any structured data regression that could reduce Google understanding of the site

8. OPEN GRAPH / SOCIAL META
Check each page for:
- og:title
- og:description
- og:url
- og:image

- missing featured images
