# Script generator production checklist

The public Attenborough and Santa pages call `/api/generate` and `/api/generate1` on Vercel. Their Vercel functions call OpenAI directly with `gpt-4o-mini`; the local Replit API server continues to use Replit AI Integrations.

**Do not enable billable access or deploy until the owner separately approves the steps below.** The Vercel Production deployment currently has a placeholder credential; merely changing this repository will not restore the live generators.

1. In Vercel's Production environment, confirm `AI_INTEGRATIONS_OPENAI_API_KEY` is stored as **Sensitive**, is scoped to the production project, and is not a placeholder. This variable name is retained for compatibility with the existing functions, but its Vercel value must be an owner-managed *direct OpenAI* API credential. Do not copy a Replit-managed integration credential. Do not put credentials in chat, source code, build logs or browser code. `AI_INTEGRATIONS_OPENAI_BASE_URL` is not used by the Vercel generator functions after this change and should not be relied on to route paid requests.
2. Before setting a valid billable credential, configure a Vercel WAF rate-limit rule covering **both** POST paths, counting by IP. A starting point is five requests per minute per IP across both paths, subject to the owner's traffic needs. Confirm the rule is active and its cost on the current Vercel plan. The functions' existing in-memory five-per-minute checks are only per warm instance and do not replace the WAF rule. Vercel's [rate-limiting documentation](https://vercel.com/docs/vercel-firewall/vercel-waf/rate-limiting) lists plan limits and pricing.
3. Set an OpenAI project-level spend alert and, if available for the account, a hard spend limit appropriate for this feature. OpenAI [notes](https://developers.openai.com/api/docs/guides/spend-limits) that hard-limit enforcement is not instantaneous, so these do not guarantee a precise maximum charge. Direct OpenAI usage is billed to the credential owner's OpenAI account; Vercel function/WAF usage is separate.
4. After explicit approval, update the Vercel Production setting and create a new Vercel deployment. [Existing deployments do not receive changed environment variables](https://vercel.com/docs/environment-variables). Check redacted logs for both endpoints, then verify one valid and one invalid request for each page. Never print or log credential values.

The backend rejects blank prompts, input longer than 2,000 characters, and prompts over the existing 25-word (Attenborough) or 75-word (Santa) caps. The existing output limits remain 500 and 600 tokens respectively. These bounds limit individual requests, not aggregate traffic or monthly charges.
