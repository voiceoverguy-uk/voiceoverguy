Placement:
Inspect the current homepage first. Place the slideshow immediately below the main introduction/demo area, above “Hear the Range”. Preserve the existing main heading, demo player, contact CTA and client-logo strip. Do not redesign or remove other sections.

Appearance:

* Use the supplied finished images as complete slides. They already contain their credit text.
* Do not add duplicate headings, captions, logos or audio buttons over the images.

Maintainability:

* Create a reusable component with a simple slide configuration containing image path, character name, production and alt text.
* Include only the finished slides I upload; no placeholders or invented credits.

Verification:
Test desktop, tablet and mobile layouts, touch swiping, keyboard controls, pause behaviour and reduced-motion settings. Check for image cropping, horizontal overflow, layout shifts and console errors.
