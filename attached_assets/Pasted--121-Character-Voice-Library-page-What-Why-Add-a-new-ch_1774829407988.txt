#121 - Character Voice Library page

What & Why
Add a new /character-voice-library page — a searchable, filterable audio demo library. Cards must be driven by a simple typed data file so new demos can be added later without touching the page code. The page must integrate cleanly with the site’s global search and the Character Demos nav dropdown.

Done looks like
- /character-voice-library loads with the intro text and 3 demo cards.
- Each card shows title, short description, and a WaveSurfer audio player.
- A search input at the top of the page live-filters cards by title, description, or aliases.
- Visiting /character-voice-library?search=jack%20fm%20voice auto-scrolls to the first best matching card, highlights it, and shows “Showing result for: jack fm voice” above the grid.
- If multiple cards match, show all matching cards, but auto-scroll/highlight the first best match.
- If no card matches, show a polite “No matching demo found” message.
- “Character Voice Library” appears in the Character Demos nav dropdown.
- Typing a character library alias or phrase such as “pixar promo” or “camp roman voice” in the global search bar returns a matching result linking to /character-voice-library?search=<encoded term>.
- Page has correct meta title, description, canonical URL, and OG tags.

Out of scope
- Categories
- Images on cards
- Per-character sub-pages
- Download buttons
- Any redesign of the existing search dropdown UI
